## Key decisions & constraints

- Картинки: только идеи из gramax (GPL-3.0 — код не копируется), транспорт —
  встроенный asset protocol; scope — рантайм-гранты открытых папок.
- NodeView конфликт: preset 'full' содержит Yfm ImgSize с nodeView на 'image';
  перекрывается только `addPlugin(cb, Priority.Highest)` (урок §10).
- Сериализатор Gravity писал пути голым текстом с `\_` — переопределён
  `overrideNodeSerializerSpec` (angle-форма при пробелах/скобках).
- pnpm 11.24 (`npx pnpm@11.24.0`); anydoc локальным path; ToasterProvider
  обязателен; monaco 0.56 пути воркеров (§7); vitest: css-stub конфиг + jsdom
  для DOM-тестов.
