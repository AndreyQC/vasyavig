## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite + TypeScript.
Gravity UI (`markdown-editor`, `uikit`), Monaco viewer, zspell-орфография, Zustand, i18next.
Приложение — в корне репозитория.

## Architecture map

| Зона | Путь | Комментарий |
|---|---|---|
| UI-строки/тема/модалка | `src\store\uiStore.ts` | persist → localStorage `vasyavig.settings` |
| Файловое дерево | `src\store\fileStore.ts`, `src\components\Sidebar\` | открытие папки/файла, watcher |
| Табы/контент/dirty | `src\store\editorStore.ts` | save/saveAs, защита md↔yfm |
| Spellcheck state | `src\store\spellStore.ts` | version бампается только при изменении |
| Редактор | `src\components\EditorArea\MarkdownEditor.tsx` | Gravity UI, preset full, key={path} |
| Spellcheck плагин | `src\lib\spellcheckExtension.ts` | PM-декорации, debounce 500 мс |
| Preview | `src\components\EditorArea\SplitPreview.tsx` | diplodoc transform + DOMPurify + mermaid |
| Monaco | `src\components\EditorArea\MonacoViewer.tsx`, `src\lib\monacoSetup.ts` | локальный бандл, read-only |
| i18n | `src\lib\i18n.ts`, `src\locales\{ru,en}\` | статический импорт JSON |
| FS команды | `src-tauri\src\commands\fs.rs`, `services\file_service.rs` | list/read/write(atomic)/metadata |
| Watcher | `src-tauri\src\commands\watcher.rs` | notify, дебаунс 300 мс, `fs-change` |
| Орфография | `src-tauri\src\commands\spellcheck.rs`, `services\spell_service.rs` | zspell, словари в `include_str!` |
| Словари | `src-tauri\resources\dictionaries\` | ru_RU + en_US, LF (см. `.gitattributes`) |

## Implemented features (Phase 1)
