## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite + TypeScript.
Gravity UI (`markdown-editor`, `uikit`), Monaco viewer, zspell-орфография, Zustand, i18next.
Приложение — в корне репозитория.

## Implemented features

Phase 1: дерево+watcher, табы, WYSIWYG/Markup/Split, save/saveAs, статус-бар,
Monaco, spellcheck ru/en/both, i18n, темы, toast-ошибки, drag-and-drop.

Phase 2: промпт при закрытии dirty-вкладки; закрытие вкладок при открытии папки;
create/delete файлов и папок.

Phase 3: конвертация офисных документов в Markdown (anydoc) с извлечением картинок.

Phase 4: URL больше не %-кодируются при редактировании (identity normalizeLink);
кнопка «Восстановить кириллицу» (декодирует существующие файлы, angle-форма при
пробелах); кнопка «Оглавление» (генерация H1–H4, модалка заменить/вставить);
кириллические якоря в превью (`supportGithubAnchors`); клик по якорю в WYSIWYG
прокручивает к заголовку.

## Key decisions & constraints

- Слаги якорей трёх видов (github-кириллица / транслит slugify / custom-id) —
  реплицируют правила `@diplodoc/transform`; прямые зависимости `markdown-it@13`,
  `github-slugger@1.5`, `slugify@1.6.6` совпадают с транзитивными версиями
  редактора/transform.
- Кнопки тулбара меняют текст через `editor.replace()` (не напрямую в store) —
  вкладка честно dirty; undo в WYSIWYG после replace сбрасывается.
- pnpm: проект требует pnpm 11.24 (store v11); при глобальном pnpm 10 —
  `ERR_PNPM_UNEXPECTED_STORE`, использовать `npx pnpm@11.24.0`.
- zspell, словари в бинарь; spellcheck только WYSIWYG; FS через `std::fs`;
  anydoc локальным path (`C:/repos/github/anydoc`).
- ToasterProvider обязателен (LESSONS_LEARNED §6); monaco 0.56 пути воркеров (§7).
