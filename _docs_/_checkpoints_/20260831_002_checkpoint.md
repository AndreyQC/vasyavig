## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite +
TypeScript. Gravity UI (`markdown-editor`, `uikit`), Monaco viewer, zspell,
Zustand, i18next. Приложение — в корне репозитория.

## Key decisions & constraints

- Имя директории: `getFileName(rootPath)` без новых полей store (Phase 6).
- Notion-таблицы: целевой формат YFM `{% table %}` не поддерживается
  `@gravity-ui/markdown-editor` 15.44 / `@diplodoc/transform` 4.77 — нужен
  собственный парсер/сериализатор + превью-плагин; Notion-UX частично готов
  встроенным YfmTableControls.
- pnpm 11.24 (`npx pnpm@11.24.0`); anydoc локальным path; ToasterProvider
  обязателен; monaco 0.56 пути воркеров (§7); vitest: css-stub + jsdom.
