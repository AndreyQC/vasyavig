## Known gaps / NOT done

- Внешние ресурсы HTML-документа блокируются (осознанно, privacy); ссылки в
  HTML не открываются вообще — shell-plugin, будущий change.
- Не-UTF-8 HTML и локальные ресурсы рядом с файлом не поддерживаются.
- Рендер HTML-части `.eml` не реализован (фиксировано спекой eml-viewer).
- mermaid-остатки: код-сплит ~1 МБ (SplitPreview импортирует mermaid
  статически), подсветка mermaid в Monaco-модалке, lazy-рендер по viewport.
- `dev` опережает `origin/dev` на накопившиеся коммиты; PR dev->main не создан.
