## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite +
TypeScript. Gravity UI (`markdown-editor`, `uikit`), Monaco, zspell, Zustand,
i18next. Приложение — в корне репозитория.

## Implemented features

Change `20260903-file-viewers-text-edit` (22/22, ручной чек-лист пользователя
2026-09-03 пройден, включая режим «Исходник» по его же запросу):

- **Просмотр изображений в отдельной вкладке**: png/jpg/jpeg/gif/webp/bmp/
  svg/ico из дерева (preview/pin-семантика), Ctrl+O, drag-and-drop; вписывание
  по умолчанию, зум кнопками и Ctrl+колесом, «Вписать/100%» от натурального
  размера; SVG только через `<img>` (скрипты не выполняются), битые файлы —
  заглушка.
- **Просмотр .eml**: режим «Разбор» — From/To/Cc/Subject/Date (RFC 2047,
  кириллица) + первая text/plain-часть (QP/base64/8bit; utf-8/windows-1251/
  koi8-r); режим «Исходник» — полный raw-текст письма (Received, DKIM и пр.);
  деградация html-only/битых файлов; никогда не dirty.
- **Редактирование текстовых файлов** (.txt/.sql/.json/…): Monaco editable,
  dirty-индикатор, Ctrl+S / Ctrl+Shift+S / «Сохранить все», промпт при
  закрытии dirty, закрепление preview первой правкой.

## Known gaps / NOT done

- Реакция вкладок на внешние изменения файла — в беклоге roadmap как
  отдельный change (единый механизм для markdown+text).
- .eml: HTML-тело и вложения не рендерятся/не сохраняются (решение
  пользователя — plain-text скоуп); RFC 2231 (параметры с продолжениями) не
  поддерживается парсером.
- Большие .eml с base64-вложениями читаются целиком в строку (латин-1) —
  при проблемах производительности выносить в Rust.
- Табы не персистентны между запусками (как и раньше).

## Key decisions & constraints

- `read_file_utf8` строго UTF-8 — для .eml добавлен `read_file_latin1`
  (единственное изменение Rust в change); парсер всегда получает байты и сам
  декодирует charset, поэтому 8bit-utf-8 письма тоже читаются корректно.
- Собственный MIME-парсер вместо крейта/библиотеки: скоуп plain-text,
  `TextDecoder` WebView2 нативно знает cp1251/koi8-r, ноль зависимостей;
  fixture-тесты на письма трёх кодировок.
- Изображения не читаются в строку вообще: вкладка хранит `content: ""`,
  URL вычисляется из path при рендере (`toAssetUrl`).
- Монополия сохранения: `isSavableKind = markdown | text`; guard в
  `updateContent` защищает вкладки-просмотрщики от любых правок.
- Ctrl+колесо в ImageViewer — нативный listener `wheel` с `passive: false`
  (React-хендлер пассивен, preventDefault не работает).
