## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite +
TypeScript. Gravity UI (`markdown-editor`, `uikit`), Monaco, zspell, Zustand,
i18next. Приложение — в корне репозитория; фазы 1-6 закрыты.

## Key decisions & constraints

- Решения D1-D13 — в `_tasks_/2026-10-25/20261025_001_harness_repos_plan.md`;
  здесь не дублируются. Ключевое: конверт не прячется от редактора,
  ULID-декорации view-only, реестр — источник правды.
- YFM-тест — отдельный файл, а не расширение commonmark-теста: YFM-спеки
  меняют разбор обычного markdown; текущая база остаётся чистой.
- YFM-билдер повторяет `YfmSpecsPreset` + `FullSpecsPreset`; опции `{}`
  (урок §15). Полный бандл и `@gravity-ui/icons` в тестах не поднимаются.
- Сериализаторные нормализации зафиксированы тестом: note по умолчанию
  получает `"Note"`, checkbox `[x]` -> `[X]`, deflist `:   ` -> `: `,
  YFM-таблица раскладывается на блоки.
- Открытые вопросы Phase 7 (формат ULID-ссылки, источник графа, мутация
  task-yaml, границы write-path, порядок задач 5/6) — в `_docs_/roadmap.md`.
- Коммиты: код и документы раздельно; `openspec` CLI — только через
  `npx --yes @fission-ai/openspec@latest`.
