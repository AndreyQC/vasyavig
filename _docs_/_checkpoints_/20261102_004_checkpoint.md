## Реализовано в 8.3

- Детерминированные фиксы (без модели, работают и без endpoint'а, D23):
  `tocStale` — replace блока списком из `buildTocPlan`; `tocMissing` — insert
  «## Оглавление» после harness-шапки (паритет с `applyTocReplace`/
  `applyTocInsert` покрыт тестами); `percentCyrillic` — декодирование цели;
  `escapedUnderscore` — `\_`→`_`; `legacyUlid` — swap схемы на `harness-ulid:`.
  Неоднозначно (oldText/якорь неуникальны) — фикса нет, finding остаётся.
- Fix-вердикты модели поддержаны только для `anchors` и `images`
  (`MODEL_FIXABLE_RULES`); replacement применяется к точному фрагменту-target,
  который вычисляет рецепт (`fixTargetFor`), — модель oldText не ищет.
  Правила с уже построенным детерминированным фиксом помечены `proposed` в
  промпте — модель только объясняет.
- Валидация двухуровневая: **схема** (JSON, известные findingId, enum,
  replacement по схеме правила) → один repair-retry → ошибка и отбрасывание
  всех вердиктов; **семантика** (count_mismatch/no_change при построении
  proposal) — отбрасывается один вердикт, счётчик в notice.
- Zero findings → модель не вызывается; модель не настроена → тихий
  детерминированный режим (как 8.2).
- Rebase pending-предложений после apply: baseHash/resultText пересчитываются,
  если oldText/якорь всё ещё однозначны, иначе stale — пакет правок одного
  прогона применяется по одному.
- Audit: детерминированные шаги пишут propose-записи без model
  (`runTool(..., {modelId: null})`), модельная стадия — `operation:"run"`
  (model/runId/путь/hash не пишется, только метаданные: path относительный,
  число findings).
- Панель: «Модель анализирует findings…» + «Отменить» (`cancelChatRun`),
  notice (`assistant.modelStage.*`: ok/okWithDropped/empty/invalid/error/
  cancelled), пояснения модели (explain/keep) под findings.
- `runCheckDocument` сохраняет прежние проверки (нет вкладки/не markdown) и
  прежние audit-записи check_document из 8.2.

## Ключевые решения и ограничения 8.3

- Полный список решений 8.1/8.2 — в `_checkpoints_/20261102_003_checkpoint.md`;
  здесь только новое.
- Запрет инструментов — отсутствие в реестре (8.2); 8.3 не добавила ни одного
  инструмента: модель вызывает только то, что уже было, рецепты ходят в
  `propose_*` из приложения.
- Модель не обязана: без endpoint'а базовая ценность (findings + фиксы)
  сохраняется (§6.1 result-документа).
- `id` findings — общий seq по всем правилам (`anchors-12-3`, а не
  `anchors-12-1`): в тестах id вычислять через `collectFindings`, не
  хардкодить (урок, пойман при написании тестов).
- `tocMissing`-фикс: якорь — первая непустая строка после шапки; пустая строка
  была бы невалидным якорем и часто неуникальна. Вставляемый блок заканчивается
  `\n\n` — пустая строка-разделитель перед якорем (applyInsert — конкатенация
  строк, не splice массива).
