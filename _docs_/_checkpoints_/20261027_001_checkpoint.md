i18next. Приложение — в корне репозитория; фазы 1-6 закрыты.

## Key decisions & constraints

- Формат ссылки — C (см. result 20261027_001): в тексте имя файла, в href
  только ULID; метаданные не дублируются (U1), источник правды — реестр.
- Кликабельность нужна только внутри Vasyavig (U2); `ulid:` вне приложения —
  текст без перехода.
- Плашечка — общий компонент с делегированием на `document` (U3); работает
  для превью и WYSIWYG по `data-ulid-dir`.
- В превью `ulid:` нужно разрешить дважды: `sanitizeOptions.allowedSchemes`
  в transform и `ALLOWED_URI_REGEXP` в DOMPurify; href затем снимается.
- WYSIWYG: декорации view-only; код-блоки и текст обычных ссылок не
  линкифицируются; инлайн-код закладки остаётся кликабельным.
- `#anchor` парсится и показывается в плашечке, но переход — отдельная задача.
- Коммиты: код и документы раздельно; openspec CLI — только через
  `npx --yes @fission-ai/openspec@latest`.
