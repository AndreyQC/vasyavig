## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite +
TypeScript. Gravity UI (`markdown-editor`, `uikit`), Monaco, zspell, Zustand,
i18next. Приложение — в корне репозитория.

## Implemented features

Change `20260904-mermaid-wysiwyg` (15/15, ручной чек-лист пользователя
2026-09-04 пройден, включая дофиксы по его репортам):

- **Рендер диаграмм в WYSIWYG**: код-фенс mermaid → SVG-карточка со skeleton;
  сериализация байт-в-байт (contentDOM — носитель текста), не dirty от показа.
- **Модала правки**: двойной клик (в т.ч. по блоку с ошибкой) — Monaco + живое
  превью; сохранение транзакцией (undo), отмена без изменений, невалидный
  исходник не блокирует.
- **Ошибки**: невалидный синтаксис — видимый код-блок + текст ошибки mermaid.
- **Тема** следует приложению (dark/default), перерисовка открытых диаграмм.
- **Кнопка «Диаграмма»** в тулбаре markdown-вкладок.

Отладочные находки сессии (по репортам пользователя): «дрожание экрана» =
отсутствие `ignoreMutation` (§12); «вставка без фенса» = открытый slice
`editor.insert()` + off-by-one позиций PM (§13). Оба урока — в LESSONS_LEARNED.

## Key decisions & constraints

- `code_block` nodeViews перекрыты ЦЕЛИКОМ: для не-mermaid языков — реплика
  минимального CodeBlockNodeView (lineWrapping выключен, lineNumbers не
  отображаются — реплицировать нечего); подсветка сохраняется — lowlight-
  декорации живут в отдельном плагине и попадают в наш contentDOM.
- `codeBlockNodeName`/`CodeBlockNodeAttr` не экспортируются пакетом —
  константы `"code_block"`/`"data-language"` локально (как IMAGE_NODE_NAME).
- mermaid.initialize глобален: превью и WYSIWYG задают одну тему — конфликта
  нет; `setMermaidTheme` не грузит библиотеку (ленивость: документ без
  диаграмм не тянет ~1 МБ).
- SVG инжектится как есть (securityLevel strict у mermaid; то же доверие, что
  в SplitPreview).
