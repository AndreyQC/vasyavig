## Что это за проект

Vasyavig — desktop-редактор markdown/YFM на Tauri 2 + React 19 + Zustand +
Vite. Основной сценарий — harness-документация: реестр документов, граф
связей, ULID-ссылки, конверты, задачи, TOC. Phase 8 добавляет ассистента по
документам; модель — в периметре, по OpenAI-совместимому протоколу.

## Реализовано в 8.2

- Read: `get_active_document`, `get_selection`, `list_open_documents`,
  `list_workspace_roots`, `get_document`, `search_documents`,
  `get_related_documents`, `list_tasks`, `check_document`.
- Модель не видит абсолютных путей: только `docId`/`rootId`, относительные
  пути от корня, имена и сниппеты; это закреплено тестами.
- `check_document` — детерминированные findings без модели; правила можно
  фильтровать (`links/anchors/toc/envelope/images/headings`), лимит 100,
  картинок — 20.
- `propose_replace` (точный `oldText`, `expectedCount`), `propose_insert`
  (`anchor`/`end`, `before/after`), `propose_create` (rootId + относительный
  путь, `.md/.yfm/.txt`, overwrite запрещён).
- Proposal хранит `baseHash`, `oldText`, `expectedCount`, якорь и полный
  `resultText`; `propose_*` не меняют буфер.
- `apply_proposal` — app-only: перепроверяет hash, число вхождений/якорь,
  применяет полный текст через `editor.replace()`, вкладка становится dirty;
  undo работает для markdown-редактора.
- Create: Rust канонизирует родителя внутри корня, запрещает `..`, абсолютные
  пути, symlink-выход и существующий файл; пустой файл + dirty-вкладка.
- Audit: время, модель, операция, относительный путь, hash, результат apply,
  число findings; содержимое и значения сущностей не пишутся.
- Панель: контекст-чипы (документ/выделение/объём), quick action проверки,
  findings, diff-карточки предложений, «Применить/Отклонить/Показать».
- `vasyavig.yaml` защищён от check/propose (`config_read_only`).
- i18n ru/en для всех новых строк; selection-расширения добавлены в WYSIWYG и Markup.

## Ключевые решения и ограничения

- Запрет инструментов — отсутствие в реестре, а не строка в промпте.
  `shell`, `run_command`, `read_file`, `write_file`, `list_dir`,
  `http_request`, `save_document`, delete/rename/move отсутствуют и покрыты тестом.
- Тиры: read-инструменты доступны `read` и `propose`; `propose_*` — только
  `propose`; `apply_proposal` — app-only и в model-реестр не попадает.
- `contentHash` — FNV-1a 128-бит: достаточен для optimistic locking, но не
  криптографическая подпись. Apply всегда перепроверяет hash и вхождения.
- Opaque id живут в памяти сессии; смена workspace сбрасывает id, proposals и findings.
- Create-путь проверяется дважды: лексически на фронтенде и канонизацией
  родителя в Rust; наружу возвращается лексический путь без `\\?\`.
- Запись — только в буфер (dirty); сохранение на диск — действие пользователя.
  Auto-apply нет; каждая операция — diff + «Применить».
- Audit собирает запись из белого списка полей; содержимое документов и
  значения сущностей туда не попадают.
- Секреты не логируются; сеть — только endpoint модели через Rust из 8.1.
- `vasyavig.yaml` — read-only, правится только UI-формой моделей.
