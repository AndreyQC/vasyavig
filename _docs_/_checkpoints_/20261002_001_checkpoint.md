## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite +
TypeScript. Gravity UI (`markdown-editor`, `uikit`), Monaco, zspell, Zustand,
i18next. Приложение — в корне репозитория.

## Implemented features

Change `20261002-html-viewer` (спека: открытие, рендер, изоляция, исходник,
read-only):

- `.html`/`.htm` открываются read-only вкладкой: дерево (preview-семантика),
  Ctrl+O, drag-and-drop; чтение штатным utf-8 `readFile`.
- «Просмотр»: рендер инлайн-стилей как в почтовом клиенте; `sandbox=""`
  запрещает скрипты/формы/попапы/навигацию; CSP-мета — внешние ресурсы.
- «Исходник»: read-only Monaco, язык html.
- Вкладка не dirty, Ctrl+S ничего не пишет.

## Key decisions & constraints

- Песочница вместо DOMPurify для HTML-вкладки: платформенная изоляция сильнее
  и сохраняет `<head>`/`<body style>` документа (design D1; DOMPurify остаётся
  для YFM-превью).
- CSP-мета инъектируется в srcdoc ПОСЛЕ пролога (xml/doctype) — иначе quirks
  mode; CSP `sandbox` не отменяет (sandbox не режет сеть).
- View-переключатель вьювера — не в Zustand: вид не переживает переключение
  вкладок и не является правкой (урок §5).
- `openspec` CLI на машине отсутствует в глобальном npm — запускать через
  `npx --yes @fission-ai/openspec@latest` (пакет `@openspec/cli` не существует).
