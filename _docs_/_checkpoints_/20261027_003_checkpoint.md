## Важная находка

`harness_ulid:` не является валидной URI-схемой по RFC 3986 (подчёркивание не
разрешено). `sanitize-html`/DOMPurify пропускают её как относительный путь —
для приложения это безопасно, href снимается после разбора; вне Vasyavig
кликабельность не требуется (U2). `allowedSchemes`/`ALLOWED_URI_REGEXP` для
`harness_ulid` — страховка; реально они нужны для legacy `ulid:`.
