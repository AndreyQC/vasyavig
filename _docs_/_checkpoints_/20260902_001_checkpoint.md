## Implemented features

Multi-root workspace (OpenSpec `20260901-multi-root-workspace`, все 17 задач):

- Workspace = упорядоченный список корней; добавление/удаление корней, смена
  цвета из палитры (9 цветов, авто-выдача, 10-й корень повторяет цвет).
- Персистентность: `.vasyavig-workspace` (JSON v1), автозапись при любом
  изменении состава/цвета, относительные пути при общем диске; последний
  workspace восстанавливается на старте; ошибка/нет файла — чистый старт.
- Вложенные корни — фича: оба отображаются секциями, файл относится к самому
  глубокому корню; один путь = одна вкладка (двойного редактирования нет);
  info-тосты при дубликате/вложенности/родителе.
- Файлы вне корней (Ctrl+O, drop файла) — вкладка с нейтральным серым тинтом,
  в дереве не появляются.
- Watcher: один мульти-watch, `fs-change` несёт путь, refresh только
  затронутого корня (дебаунс 300 мс на корень).
- Dirty-промпты: удаление корня, «Открыть workspace», «Новый workspace»
  (сценарий «открыть папку вместо» демонтирован).
- UI: секции с тинтом, chip, палитра раскрывается под заголовком корня;
  шапка сайдбара закреплена, workspace-меню компактное; активная вкладка —
  широкая рамка цвета корня.

Ручной чек-лист 6.2 пройден пользователем 2026-09-02 (цвета/темы, вложенные,
файл вне корней, восстановление после перезапуска, 10-й корень, dirty-промпт,
точечный refresh).

## Key decisions & constraints

- Класс темы Gravity: `g-root_theme_light` (BEM `block_mod_val`), ThemeProvider
  вешает его на `<body>` — свои CSS-переменные темы объявлять на этом
  селекторе (`g-root_light` не существует).
- Цвет корня хранится именем токена, не hex; тинты — `color-mix` с
  `--g-color-base-background`.
- Активная вкладка — `outline` (не участвует в layout), не `border` (§8).
- Селекторы Zustand — только примитивы/стабильные ссылки; `resolveRoot`-цвет
  вкладок — `useMemo` (§3); цвет нигде не дублируется.
- В vitest `lib/i18n` мокается: он тянет `@gravity-ui/uikit`, который
  экстернализируется и ломается на CSS-импортах (css-stub конфига не покрывает
  externalized-пакеты — кандидат на `ssr.noExternal`).
- Удаление корня закрывает только вкладки, теряющие корень (вложенные
  остаются); workspace-свитч закрывает все вкладки после промпта.
