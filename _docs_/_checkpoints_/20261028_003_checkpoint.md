## Решения и ограничения (новые)

- `alias` — опциональное поле workspace-файла **без смены версии** (v1):
  старые парсеры неизвестные поля игнорируют, совместимость в обе стороны.
- Свёрнутость секций и позиция курсора — session-only (в workspace-файл не
  пишутся); недавние workspace — persist (localStorage, max 5).
- Порядок плашек не через DnD: window-level `onDragDropEvent` (Tauri) может
  конфликтовать с внутренним HTML5 DnD на WebView2 — порядок через
  контекст-меню.
- Хоткеи могут перехватываться browser accelerator keys WebView2 — если
  приёмка покажет перехват, отдельный шаг на additionalBrowserArgs.
- В WYSIWYG «строка:столбец» — приближение (блок верхнего уровня:офсет),
  в Markup — точные строка:столбец.
