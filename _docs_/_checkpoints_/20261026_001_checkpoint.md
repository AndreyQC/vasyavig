## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite +
TypeScript. Gravity UI (`markdown-editor`, `uikit`), Monaco, zspell, Zustand,
i18next. Приложение — в корне репозитория; фазы 1-6 закрыты.

## Key decisions & constraints

- D1-D13 зафиксированы в
  `_docs_/_tasks_/2026-10-25/20261025_001_harness_repos_plan.md` (разделы
  «Решения» и «Решения по открытым вопросам»); здесь не дублируются.
- Ключевое: конверт не прячется от редактора (штатный Html-экстеншн Gravity),
  защитный слой «вырезать/вернуть» отклонён — иначе ломаются Markup-режим и
  dirty-сравнение (D2); риск потери при Ctrl+A -> Delete принят, ловится
  `make doc-check`.
- ULID-декорации WYSIWYG — view-only, сериализацию не затрагивают; клики и
  резолв — через общий `openUlidTarget`.
- Реестр — источник правды для ссылок; неизвестный валидный ULID не
  переходит (решение пользователя).
- Task-yaml не интерпретируется: гарантируется только сохранность (D8).
- Прецедент тестов Gravity-редактора: сабпути пакета
  (`@gravity-ui/markdown-editor/core`, `extensions/*/specs.js`), не полный
  бандл — `LESSONS_LEARNED.md` §15.
- `openspec` CLI глобально не установлен: `npx --yes
  @fission-ai/openspec@latest`.
