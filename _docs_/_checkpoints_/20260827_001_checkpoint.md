## Что это за проект

Vasyavig — desktop-редактор Markdown/YFM на Tauri v2 (Rust) + React 19 + Vite + TypeScript.
Gravity UI (`markdown-editor`, `uikit`), Monaco viewer, zspell-орфография, Zustand, i18next.
Приложение — в корне репозитория.

## Implemented features (Phase 1)

Файловое дерево с автообновлением; табы; WYSIWYG/Markup/Split; сохранение Ctrl+S /
Save As с модалкой md↔yfm; статус-бар; Monaco read-only; spellcheck ru/en/both с
live-подчёркиваниями; i18n ru/en; темы; toast-ошибки; drag-and-drop; Ctrl+O.

Phase 2: промпт при закрытии dirty-вкладки; закрытие вкладок при открытии папки
(сохранить все / сбросить / отмена); создание/удаление файлов и папок (Rust-команды
`create_file`/`delete_path` + контекстное меню дерева и кнопки Sidebar).

Phase 3: при открытии офисного документа (Word/PPT/Excel/ODF/RTF/EPUB/CSV/PDF) —
модалка «Создать Markdown-версию»; anydoc конвертирует в `.md`, извлекает изображения
в `<имя>_assets/` и проставляет ссылки. Ресайзбл-сайдбар (сплиттер в `Layout`).

## Key decisions & constraints

- zspell (не hunspell-rs); словари зашиты в бинарь.
- Spellcheck только WYSIWYG.
- Команды FS работают через `std::fs` (не tauri-plugin-fs) — для create/delete новые
  permissions не нужны, только регистрация в `generate_handler!` (lib.rs).
- anydoc подключён локально (`path = "C:/repos/github/anydoc"`): в нём добавлена
  `to_markdown_with_assets` — встроенные изображения → файлы + ссылки в markdown.
- ToasterProvider обязателен (LESSONS_LEARNED §6); monaco 0.56 пути воркеров (§7).
