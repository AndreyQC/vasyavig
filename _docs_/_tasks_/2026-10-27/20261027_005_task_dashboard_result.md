1. **Значок в секции корня.** В сайдбаре секция `lm_hrdo_2`: слева от имени —
   маленький кубик (иконка Boxes3), рядом с цветным кружком корня. Tooltip:

2. **Кнопка «Задачи».** В шапке сайдбара (строка кнопок под «Добавить папку»)
   появляется кнопка со списком-чекмарком. Видна только если есть harness-корень.
3. **Панель дашборда.** Клик по кнопке -> сайдбар переключается с дерева на
   панель задач: сверху фильтры (статус, тип, исполнитель, поиск) и кнопка

4. **Содержимое списка.** Ожидаются строки по документам типов `tracker` и
   `backlog` (в примере их десятки): бейджи «Выполнена» (зелёный),

   Названия — из реестра (title), путь — от корня репо.
5. **Фильтры.** Выбор статуса «Выполнена» -> остаются только завершённые;
   выбор типа backlog -> только бэклоги; поиск по слову (например DATAOCEAN)
   -> сужает список. Пустой результат -> «Задачи (task-yaml) не найдены» +
   подсказка про make doc-index.
6. **Переход к документу.** Клик по строке -> документ открывается вкладкой

7. **Живой статус.** Открыть задачный .md, в конверте task-yaml поменять
   status: open -> status: done, сохранить -> через ~1-2 с (watcher +

8. **Пересборка реестра.** В lm_hrdo_2 выполнить make doc-index -> список
   дашборда пересчитывается сам (событие по documents.jsonl).
9. **Темы и языки.** Переключить тёмную тему и English: подписи бейджей и
   подсказок меняются, вёрстка не ломается.
