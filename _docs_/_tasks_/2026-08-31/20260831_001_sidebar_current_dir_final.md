## Контекст задачи

Запрос пользователя (2026-08-31): показать название открытой директории явно
(до этого — только полный путь мелким текстом внизу сайдбара); переименовать
кнопку; перенести запрошенные идеи в беклог. Notion-таблицы по итогам
обсуждения отложены в беклог (формат `{% table %}` не поддерживается
текущими версиями библиотек — детали в roadmap).

## Решения

1. Блок «Текущая директория» — в `SidebarHeader.tsx`, над кнопкой:
   label (muted) + имя папки bold с ellipsis, тултип с полным `rootPath`.
   Показывается только при открытой папке.
2. `sidebar.openFolder`: «Открыть папку» -> «Открыть директорию» /
   «Open directory»; новый ключ `sidebar.currentDirectory` (ru/en).
3. Старый показ пути в `sidebar-footer` (App.tsx) удалён, CSS почищен.
4. Roadmap-беклог: добавлена работа с git; переформулированы пункты про
   Notion-таблицы (целевой формат `{% table %}` + `{% colwidth %}`),
   вставку картинок, ресайз картинок.
