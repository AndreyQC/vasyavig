# Просмотр HTML-файлов (письма-черновики) — план

> Дата: 2026-10-02 | Ветка: dev | Статус: реализовано (см. `_result`)

> Контекст:
> - `openspec/changes/20261002-html-viewer/` — proposal, спека `html-viewer`, design, tasks
> - `_docs_/REFRESH_CONTEXT.md`, `LESSONS_LEARNED.md`
> - Преемственность: viewer-спеки `eml-viewer`, `image-viewer` (openspec/specs/)

## Задача

В рабочих репозиториях появились самодостаточные HTML-файлы — черновики писем
для отправки по почте (всё форматирование в инлайн-стилях: шапка To/Cc/Тема,
таблицы, SQL-блоки). Расширение `.html` не входило ни в один список
`src/lib/constants.ts` → `getFileKind` возвращал `"unsupported"`, файл нельзя
открыть. Нужен просмотр в отрендеренном виде, как в почтовом клиенте.

## Цели

1. `.html`/`.htm` открываются в отдельной read-only вкладке (дерево, Ctrl+O,
   drag-and-drop), preview-семантика вкладок — без правок спеки preview-tabs.
2. Режим «Просмотр»: рендер с инлайн-стилями в изолированной песочнице;
   скрипты, формы, навигация и внешние ресурсы запрещены.
3. Режим «Исходник»: read-only Monaco с подсветкой html (worker уже
   зарегистрирован в `monacoSetup.ts`).

## Решения (детали — design.md D1–D5)

- **D1**: рендер — `<iframe srcdoc sandbox="">`, не DOMPurify+innerHTML:
  платформенная изоляция сильнее, `<head>`/`<body style>` документа
  сохраняются. `allow-scripts`/`allow-same-origin` не выдаём никогда.
- **D2**: внешние ресурсы блокирует инъекция CSP-`<meta>` в начало документа
  (`injectCspMeta`): после `<head...>` / как новый `<head>` после `<html...>` /
  после xml/doctype-пролога (иначе quirks mode). Идемпотентно.
- **D3**: новый `FileKind "html"` (не расширение TEXT_EXTENSIONS) — read-only
  семантика image/email переиспользуется без правок store.
- **D4**: чтение штатным `readFile` (utf-8); вид «Просмотр/Исходник» —
  локальный useState (не состояние документа, урок §5).
- **D5**: раскладка — тоггл режимов + «лист» с рамкой; фон документа задаёт
  сам файл (тема приложения на рендер не влияет).

Не-цели: редактирование HTML, рендер HTML-части `.eml`, открытие ссылок во
внешнем браузере, не-UTF-8 кодировки, локальные ресурсы рядом с файлом,
конвертация в Markdown.

## Проверки

- Юнит: `getFileKind`/`getMonacoLanguage` (html/htm), открытие `.html` в
  `fileStore.test.ts` (readFile, kind, preview), CSP-инъекция (полный
  документ, без head, фрагмент, XHTML-пролог, идемпотентность).
- `pnpm test`, `npx tsc --noEmit`, `npx vite build`, `openspec validate`.
- Ручная GUI-приёмка в `pnpm tauri dev` на файле-примере из запроса.

## Риски

- CSP-инъекция ломает экзотический HTML → консервативная вставка после
  первого вхождения тега + тесты на типовых формах.
- Внешние картинки «пропадают» → осознанно (privacy, трекинг-пиксели),
  зафиксировано спекой; ослабление — будущим change.
