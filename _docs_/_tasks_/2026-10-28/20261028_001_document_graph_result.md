## 4. GUI-приёмка

### Метод

Computer Use в этой сессии недоступен (`Computer Use is unavailable for this
node_repl session`), поэтому приложение управлялось **настоящим** способом:
dev-сборка запущена с `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222`,
далее — Chrome DevTools Protocol по WebView2: клики — реальными событиями мыши
(`Input.dispatchMouseEvent`), скриншоты — `Page.captureScreenshot`, состояние —
`Runtime.evaluate`. Приложение при этом живое: настоящий Tauri IPC, настоящий
реестр `C:\repos\reksoft\locomoko\lm_hrdo_2` (1814 записи).

Окно ОС осталось 800x600 (в разрешении `plugin:window|allow-set-size` нет);
вьюпорт расширен на уровне CDP до 1500x950 — на снимки это не влияет, на
раскладку влияет (панели графа местами теснее, чем в широком окне).

## 5. Известные ограничения / NOT done

- **Источник — реестр, не БД** (D2): связи живут в `documents.jsonl`; когда
  реестр переедет в БД, меняется только источник записей.
- **Симметризация `related` на чтение**: в UI видны и «обратные» связи, которых
  нет в самом документе; в реестре они записаны только со стороны соседа.
- **Дерево обзора показывает иерархию `based_on`, а не все связи**: связи
  `related` отмечены счётчиком у узла, но не разворачиваются в дереве — иначе
  структура перестала бы быть деревом.
- **Клик по узлу уводит с панели на документ** (D12): возврат — клик по вкладке
  «Граф». Панель и документ одновременно не видны (в отличие от варианта
  «колонка рядом с документом», который предлагался в обсуждении).
- **Переход к якорю `#<anchor>`** — вне скоупа (Phase 8).
- **Редактирование связей** — вне скоупа: связи только читаются.
- **Репозиторий в корне-родителе** находится по реестру в дереве, но путь
  репозитория восстанавливается из узла дерева: если корень-родитель добавлен
  до перезагрузки дерева, панель увидит репозиторий после обновления дерева.
- **1814 записей** — дерево строится целиком при смене фильтров; расчёт леса
  занимает единицы миллисекунд, но при росте реестра до десятков тысяч
  понадобится виртуализация списка.
- Задача 7 (write-path конвертов и реестра) — не начата.
