## Цель

Закрыть четыре замечания из эксплуатации: потеря правок при закрытии вкладки,
корректное закрытие вкладок при открытии новой папки, создание и удаление
файлов/папок из дерева.

## Пункты

### 1. [fix, P0] Потеря правок при закрытии вкладки

**Проблема.** При закрытии вкладки с несохранёнными изменениями запрос о
сохранении не появляется — правки теряются.

**Ожидание.** Закрытие «грязной» вкладки (dirty) показывает диалог
«Сохранить / Не сохранять / Отмена»; чистая вкладка закрывается без запроса.

**Ориентиры реализации.**
- `dirty` и `content` уже живут в `editorStore` (LESSONS_LEARNED §3, §5) —
  читать их в обработчике закрытия вкладки (`src\store\editorStore.ts`, `closeTab`).
- Обработчик крестика — `src\components\EditorArea\EditorTabs.tsx`.
- Не смешивать с закрытием окна (`onCloseRequested`, LESSONS_LEARNED §4) —
  здесь речь о вкладке, не об окне.

### 2. [feature, P1] «Открыть папку» закрывает открытые вкладки

- При выборе новой папки все открытые вкладки закрываются.
- Если среди них есть несохранённые — показать их список и предложить:
  **Сохранить все / Сбросить изменения / Отмена**.
- Ориентир: перехватить открытие папки (store/hook `useTauriFS`/`fileStore`),
  собрать dirty-вкладки, показать модалку (`src\components\Modals\`).

### 3. [feature, P2] Создание нового файла из дерева

- Доступно через контекстное меню дерева (правый клик) и кнопку «Создать»
  в заголовке Sidebar.
- Новый файл создаётся в активной (выбранной) папке дерева; если папка не
  выбрана — в корень открытого каталога.
- По умолчанию создаётся `.md`; расширение можно изменить после создания
  (Markdown/YFM/YAML/JSON/txt и т.д.).
- Нужна Rust-команда создания файла (расширить `src-tauri\src\commands\fs.rs`)
  и обновление дерева (watcher уже есть — Phase_01).

### 4. [feature, P2] Удаление файлов и папок

- Удаление файлов и папок (папки — рекурсивно), безвозвратно (не в Recycle
  Bin), с обязательным подтверждением.
- Доступно через контекстное меню дерева (правый клик) и кнопку «Удалить»
  в заголовке Sidebar.
- Rust-команда удаления; если удаляемый файл открыт — закрыть его вкладку.

## Проверки

- Закрытие dirty-вкладки показывает диалог; правки не теряются.
- «Открыть папку» с несохранёнными файлами показывает список и три действия.
- Создание `.md` в активной папке дерева; удаление файла/папки с подтверждением;
  дерево обновляется (watcher).
