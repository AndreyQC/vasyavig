# html-viewer Specification

## Purpose

Просмотр самодостаточных HTML-файлов (черновики писем: всё форматирование в
инлайн-стилях) в отдельной вкладке приложения без браузера: отрендеренный вид
в изолированной песочнице и режим исходника.

## Requirements

### Requirement: Открытие .html/.htm в отдельной вкладке

Выбор файла `.html`/`.htm` в файловом дереве, диалог Ctrl+O и
перетаскивание файла в окно SHALL открывать его в отдельной вкладке только для
просмотра. Вкладка подчиняется семантике preview-вкладок: одиночный клик —
preview, двойной клик — закрепление.

#### Scenario: Открытие черновика письма из дерева

- **WHEN** пользователь дважды кликает файл `письмо.html` в дереве
- **THEN** открывается закреплённая вкладка с отрендеренным содержимым письма

#### Scenario: Preview одним кликом

- **WHEN** пользователь однократно кликает файл `report.htm`
- **THEN** файл открывается preview-вкладкой и замещается следующей
  preview-вкладкой при переходе к другому файлу

### Requirement: Режим «Просмотр» рендерит самодостаточный HTML

Вкладка HTML SHALL открываться в режиме «Просмотр»: документ отображается
отрендеренным — инлайн-стили, таблицы, код-блоки и шапки письма выглядят как в
почтовом клиенте. Рендер SHALL происходить в изолированной области (песочнице)
внутри вкладки, не затрагивая остальное приложение.

#### Scenario: Письмо с таблицей и SQL-блоком

- **WHEN** открыт HTML-файл письма с инлайн-стилями (таблица, `<pre>` с SQL)
- **THEN** таблица и код-блок отображаются с форматированием, заданным
  инлайн-стилями файла

#### Scenario: Тёмная тема приложения

- **WHEN** включена тёмная тема приложения, открыт HTML-файл
- **THEN** документ отображается с собственным оформлением файла (включая
  светлый фон письма) на подложке области просмотра

### Requirement: Изоляция и безопасность рендера

Рендер SHALL запрещать исполнение скриптов, отправку форм, всплывающие окна и
навигацию (в том числе переход по ссылкам и meta-refresh) внутри приложения.
Загрузка внешних ресурсов (изображения, стили, шрифты по сети) SHALL быть
заблокирована; допустимо только содержимое, встроенное в сам файл.

#### Scenario: Скрипт не исполняется

- **WHEN** файл содержит `<script>alert(1)</script>`
- **THEN** скрипт не выполняется, остальной документ отображается

#### Scenario: Внешняя картинка не загружается

- **WHEN** файл содержит `<img src="https://example.com/pixel.gif">`
- **THEN** сетевой запрос не выполняется, остальной документ отображается

#### Scenario: Ссылка не ведёт навигацию приложения

- **WHEN** пользователь кликает ссылку `<a href="https://...">` в документе
- **THEN** навигация внутри приложения не происходит (открытие ссылки вне
  приложения — опционально и может отсутствовать)

### Requirement: Режим «Исходник»

Вкладка HTML SHALL предоставлять переключатель видов «Просмотр / Исходник».
Вид «Исходник» SHALL показывать полный текст файла целиком, read-only, с
подсветкой синтаксиса HTML. Переключение SHALL менять только вид, не файл и не
состояние вкладки.

#### Scenario: Просмотр разметки

- **WHEN** пользователь переключается в режим «Исходник»
- **THEN** отображается полный HTML-исходник файла с подсветкой, без
  возможности правки

#### Scenario: Возврат к просмотру

- **WHEN** пользователь переключается обратно в режим «Просмотр»
- **THEN** снова отображается отрендеренный документ

### Requirement: Вкладка HTML не редактируется

Вкладка HTML SHALL быть только для просмотра: никогда не dirty, Ctrl+S не
выполняет записи, закрытие без подтверждения.

#### Scenario: Ctrl+S на вкладке HTML

- **WHEN** активна вкладка HTML и пользователь нажимает Ctrl+S
- **THEN** файл не перезаписывается, статус вкладки не меняется
