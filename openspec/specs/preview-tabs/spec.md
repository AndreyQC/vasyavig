# preview-tabs Specification

## Purpose

Навигация по файлам дерева не замусоривает панель вкладок: одиночный клик
открывает эфемерную вкладку просмотра, которая закрепляется двойным кликом или
первой правкой и закрывается сама при переходе к следующему файлу.

## Requirements

### Requirement: Одиночный клик открывает preview-вкладку

Одиночный клик по файлу в дереве SHALL открывать файл в preview-вкладке
(эфемерной). Повторный одиночный клик по файлу с уже открытой вкладкой SHALL
активировать существующую вкладку, не меняя её статуса закрепления и не создавая
дубль.

#### Scenario: Первый клик по файлу

- **WHEN** пользователь однократно кликает файл в дереве
- **THEN** файл открывается preview-вкладкой и становится активным

#### Scenario: Повторный клик по тому же файлу

- **WHEN** preview-вкладка файла уже открыта, пользователь однократно кликает
  тот же файл в дереве
- **THEN** вторая вкладка не создаётся, статус preview не меняется

### Requirement: Переход к другому файлу закрывает preview-вкладку

При открытии нового файла preview-вкладкой предыдущая незакреплённая
preview-вкладка SHALL закрываться автоматически, без запроса подтверждения
(незакреплённая preview-вкладка не содержит несохранённых правок). Закреплённые
вкладки не затрагиваются.

#### Scenario: Просмотр нескольких файлов подряд

- **WHEN** пользователь последовательно однокликает файлы A, B, C
- **THEN** в панели остаётся одна preview-вкладка — последнего открытого файла;
  закреплённые вкладки не закрываются

#### Scenario: Закрытие без промпта

- **WHEN** preview-вкладка закрывается автоматически при переходе к другому
  файлу
- **THEN** диалог подтверждения не показывается

### Requirement: Двойной клик открывает закреплённую вкладку

Двойной клик по файлу в дереве SHALL открывать файл закреплённой вкладкой. Если
preview-вкладка этого файла уже открыта, двойной клик SHALL закреплять её.

#### Scenario: Двойной клик по новому файлу

- **WHEN** пользователь дважды кликает файл, вкладки которого нет
- **THEN** файл открывается закреплённой вкладкой

#### Scenario: Двойной клик по открытому preview

- **WHEN** preview-вкладка файла открыта, пользователь дважды кликает этот же
  файл в дереве
- **THEN** вкладка закрепляется и не закроется при переходе к другому файлу

### Requirement: Первая правка закрепляет preview-вкладку

Первое изменение содержимого в preview-вкладке редактируемого файла SHALL
закреплять вкладку. Закреплённая правкой вкладка не закрывается при переходе к
другому файлу.

#### Scenario: Правка в preview-вкладке

- **WHEN** пользователь начинает редактировать документ в preview-вкладке, затем
  однокликает другой файл в дереве
- **THEN** отредактированная вкладка остаётся открытой (закреплена), новый файл
  открывается preview-вкладкой

### Requirement: Явное открытие файла создаёт закреплённую вкладку

Открытие файла через диалог (Ctrl+O) или drag-and-drop файла в окно SHALL
создавать сразу закреплённую вкладку, независимо от наличия preview-вкладок.

#### Scenario: Открытие через диалог

- **WHEN** пользователь открывает файл через Ctrl+O
- **THEN** файл открывается закреплённой вкладкой

### Requirement: Preview-вкладка визуально отличима

Preview-вкладка SHALL визуально отличаться от закреплённой (стиль подписи),
чтобы пользователь понимал, какие вкладки исчезнут при переходе к другому файлу.

#### Scenario: Отличие стиля

- **WHEN** открыты preview-вкладка и закреплённая вкладка
- **THEN** их подписи визуально различимы

### Requirement: Семантика едина для всех типов вкладок

Preview-семантика SHALL применяться ко всем типам вкладок (markdown и
просматриваемые текстовые). Для вкладок без редактирования закрепление
происходит двойным кликом.

#### Scenario: Просмотр текстового файла

- **WHEN** пользователь однокликает `.json` файл, затем однокликает markdown-файл
- **THEN** preview-вкладка текстового файла закрывается, markdown открывается
  preview-вкладкой
