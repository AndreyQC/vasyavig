# workspace-file

## Purpose

Персистентность состава workspace в переносимом файле `.vasyavig-workspace`:
формат, автозапись изменений, относительные пути, восстановление последнего
workspace при запуске приложения.

## Requirements

### Requirement: Формат файла workspace

Workspace SHALL сохраняться в JSON-файле с расширением `.vasyavig-workspace`.
Файл содержит версию формата и упорядоченный список папок; для каждой папки
указаны путь и цвет.

#### Scenario: Чтение файла

- **WHEN** открывается существующий корректный `.vasyavig-workspace`
- **THEN** корни восстанавливаются в порядке файла, каждому назначается его цвет

#### Scenario: Незнакомая версия формата

- **WHEN** файл содержит версию формата, не поддерживаемую приложением
- **THEN** приложение сообщает ошибку и стартует с пустым workspace, не завершаясь аварийно

### Requirement: Автозапись изменений

Любое изменение workspace (добавление корня, удаление корня, смена цвета корня)
SHALL автоматически записываться в файл workspace немедленно, без отдельного
действия «сохранить workspace».

#### Scenario: Добавление корня записывается на диск

- **WHEN** пользователь добавляет папку в workspace с уже выбранным файлом
- **THEN** файл workspace на диске сразу содержит новую папку и её цвет

#### Scenario: Первый корень без файла workspace

- **WHEN** пользователь добавляет папку, а файл workspace ещё не выбран
- **THEN** приложение запрашивает место для создания файла workspace и только
  после выбора добавляет папку

### Requirement: Относительные пути

Путь папки в файле workspace MUST храниться относительным к каталогу файла
workspace, когда папка доступна относительным путём; абсолютный путь
используется только когда относительный невозможен (например, другой диск в
Windows).

#### Scenario: Папка доступна относительно

- **WHEN** workspace-файл лежит в `C:/work/docs.vasyavig-workspace`, а папка —
  `C:/work/project`
- **THEN** в файле путь папки записан как `./project`

#### Scenario: Папка на другом диске

- **WHEN** workspace-файл на диске `C:`, а папка на диске `D:`
- **THEN** в файле путь папки записан абсолютным

### Requirement: Восстановление последнего workspace

При запуске приложение SHALL загружать последний открытый workspace. Если файл
отсутствует, нечитаем или некорректен — приложение стартует с пустым workspace
без аварийного завершения.

#### Scenario: Перезапуск приложения

- **WHEN** приложение запускается после сессии с workspace
- **THEN** корни и цвета последнего workspace восстановлены

#### Scenario: Файл workspace удалён вручную

- **WHEN** запускается приложение, а файл последнего workspace удалён с диска
- **THEN** приложение стартует с пустым workspace и пустым сайдбаром

### Requirement: Открытие и создание workspace

Пользователь SHALL иметь возможность открыть другой `.vasyavig-workspace` и
создать новый workspace-файл. Обе операции заменяют текущий состав корней;
при наличии несохранённых вкладок требуется подтверждение.

#### Scenario: Открытие другого workspace с несохранёнными вкладками

- **WHEN** открыты вкладки с правками и пользователь открывает другой
  workspace-файл
- **THEN** показывается подтверждение; при отказе текущий workspace не меняется

#### Scenario: Новый workspace

- **WHEN** пользователь создаёт новый workspace и подтверждает замену
- **THEN** корни сбрасываются, вкладки закрываются, выбранный файл становится
  файлом текущего workspace
