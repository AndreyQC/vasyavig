# Proposal

## Why

В рабочих репозиториях появились самодостаточные HTML-файлы — черновики писем
для отправки по почте (всё форматирование в инлайн-стилях: таблицы, SQL-блоки,
шапка To/Cc/Тема). Сейчас расширение `.html` не входит ни в один список
`src/lib/constants.ts`, `getFileKind` возвращает `"unsupported"`, и файл
нельзя даже открыть. Просмотр таких файлов в исходном виде (как текст) не даёт
представления о письме — нужен рендеринг.

## What Changes

- Новое расширение просмотра: `.html` / `.htm` открываются во вкладке
  **только для просмотра** (новый `FileKind` `"html"`), по образцу вкладок
  image/email.
- Режим **«Просмотр»** (по умолчанию): HTML рендерится как в почтовом
  клиенте — инлайн-стили, таблицы, код-блоки; скрипты и навигация запрещены
  (песочница), внешние ссылки не открываются внутри приложения.
- Режим **«Исходник»**: read-only Monaco с подсветкой `html` (html-worker уже
  зарегистрирован в `monacoSetup.ts`).
- Вкладка не редактируется и не бывает dirty: Ctrl+S ничего не записывает,
  закрытие без подтверждения — семантика как у вкладок писем/картинок.
- Preview-семантика вкладок (одиночный клик — preview, двойной — закрепление)
  применяется к HTML-вкладкам автоматически, без изменений спеки preview-tabs.

## Capabilities

### New Capabilities

- `html-viewer`: просмотр самодостаточных HTML-файлов (`.html`, `.htm`) в
  отдельной read-only вкладке: отрендеренный вид в изолированной песочнице и
  режим исходника. Развивает линейку viewer-спек `eml-viewer`, `image-viewer`.

### Modified Capabilities

_(нет — preview-tabs сформулирована без перечисления типов; text-file-editing
не затрагивается, т.к. HTML-вкладка не редактируется)_

## Impact

- `src/lib/constants.ts` — новый `HTML_EXTENSIONS = ["html", "htm"]`.
- `src/lib/utils.ts` — `FileKind` + `getFileKind` (ветка html);
  `getMonacoLanguage` — маппинг `html/htm → html`.
- `src/components/EditorArea/HtmlViewer.tsx` — новый компонент (рендер в
  sandboxed iframe + переключатель режимов, по паттерну `EmlViewer`).
- `src/App.tsx` — маршрутизация `kind === "html"` → `HtmlViewer`.
- `src/store/fileStore.ts` — чтение файла штатным `readFile` (utf-8).
- `src/lib/i18n.ts` — строки режимов; CSS `EditorArea.css` — стили вьювера.
- Новых зависимостей нет (DOMPurify уже в проекте; iframe-sandbox не требует
  пакетов). Rust-часть не меняется.
