# Tasks: mermaid-диаграммы в редакторе WYSIWYG

> Ссылки: требования — `specs/mermaid-wysiwyg/spec.md`, подход — `design.md`
> (D1–D5). Проверки: `pnpm test` (vitest), `npx tsc --noEmit`,
> ручной прогон `pnpm tauri dev` (Rust не затрагивается).

## 1. Рендерер диаграмм

- [x] 1.1 Модуль `src/lib/mermaidRenderer.ts`: ленивый `import("mermaid")`,
  `setTheme(dark)`, `renderDiagram(source) → {svg} | {error}` (уникальный
  id, offscreen-контейнер с `finally remove()`, нормализация ошибок, без
  исключений наружу), мини-эмиттер `onThemeChange` (D1/D4). Проверка:
  unit-тесты чистых хелперов (id-уникальность, нормализация текста ошибки);
  рендер-SVG — в ручном прогоне (DOM API).
- [x] 1.2 Подключение темы: `setTheme` вызывается при инициализации и смене
  `useThemeValue()`; подписчики эмиттера перерисовываются. Проверка: ручной
  прогон — переключение темы перерисовывает диаграмму в WYSIWYG.

## 2. NodeView в WYSIWYG

- [x] 2.1 `src/lib/mermaidWysiwygExtension.ts`: плагин Priority.Highest с
  `nodeViews.code_block`; константы `"code_block"`/`"data-language"` с
  комментарием о неэкспортируемости (D2). Проверка: tsc; расширение
  подключается в MarkdownEditor без ошибок консоли.
- [x] 2.2 `MermaidNodeView`: карточка + skeleton, рендер через
  `renderDiagram`, `update(node)` — перерендер при изменении текста, выход
  на fallback при смене языка, dblclick → `pendingMermaidEdit` (D3).
  Проверка: документ с валидной диаграммой рендерит SVG; правка через
  модалку обновляет диаграмму на месте; undo откатывает.
- [x] 2.3 `FallbackCodeNodeView`: реплика `pre[data-language] >
  code.hljs.<lang> > contentDIV` + update при смене языка (D2). Проверка:
  sanity-тест структуры DOM (паттерн `pluginNodeViews.sanity.test.ts`);
  ручный прогон — обычные код-блоки (js/json/yaml) с подсветкой, курсор
  внутри блока, enter/backspace работают.
- [x] 2.4 Ошибки рендера: невалидный исходник — блок остаётся код-блоком с
  сообщением об ошибке, dblclick открывает модалку (D5). Проверка: ручной
  прогон на сломанной диаграмме; документ редактируется.
- [x] 2.5 Не-dirty от показа: открытие документа с диаграммой в WYSIWYG не
  делает вкладку dirty; сохранение без правок не меняет файл байт-в-байт
  (кириллица в диаграмме). Проверка: ручной прогон + при необходимости
  unit-тест сериализации через editor API.

## 3. Модалка редактора

- [x] 3.1 `MermaidModal.tsx`: Gravity Modal, Monaco слева (`MonacoViewer`

- [x] 3.3 Жизненный цикл: закрытие вкладки/размонтирование редактора

  закрыть вкладку при открытой модалке, приложение не падает.
