# Proposal: mermaid-диаграммы в редакторе WYSIWYG

> Дата: 2026-09-04 | Статус: draft
> Контекст: чекпойнт `_docs_/_checkpoints_/20260903_002_checkpoint.md`, беклог
> `_docs_/roadmap.md` («Mermaid в WYSIWYG»), исследование грамакс
> `_docs_/GRAMAX_RESEARCH_RESULT.md` §2, решения пользователя 2026-09-04
> (скоуп: рендер + модалка; тема — следовать приложению).

## Why

Mermaid-диаграммы сегодня рендерятся только в превью (SplitView) и в
Markup-режиме видны как код. В WYSIWYG — основном режиме редактора —
диаграмма выглядит как голый код-блок: автор документации не видит, что
именно он описывает, и не может быстро поправить исходник. Это последний
тип контента, который «слеп» в визуальном режиме.

## What Changes

- **Рендер диаграмм в WYSIWYG**: код-блок с языком `mermaid` отображается
  как SVG-диаграмма прямо в документе (nodeView на code-fence). Исходный
  markdown не меняется — сериализация код-блока остаётся канонической
  (```` ```mermaid ```` фенс), документ не становится dirty от показа.
- **Модалка-редактор исходника**: двойной клик по диаграмме (или код-блоку
  с ошибкой) открывает модалку — Monaco-редактор слева (язык mermaid),
  живое превью справа (тот же рендерер, debounce). Сохранение переносит
  правки в документ через editor API (undo работает), вкладка становится
  dirty — запись в файл за пользователем (как у кнопок «Оглавление»).
- **Кнопка «Диаграмма» в тулбаре** markdown-вкладки (дополнение по запросу
  пользователя 2026-09-04): вставка шаблонного mermaid-блока в позицию
  курсора в обоих режимах.
- **Ошибки рендера**: невалидный синтаксис — блок остаётся код-блоком с
  дружелюбной ошибкой (текст mermaid), клик открывает модалку для правки.
- **Тема диаграмм следует теме приложения** (dark/default, как в превью);
  ленивая загрузка mermaid (`import("mermaid")` при первой диаграмме);
  уникальные id рендеров, offscreen-контейнер с удалением в `finally`
  (приёмы gramax §2.1).
- **Вне скоупа**: drag-ресайз диаграмм (карточка вписана по ширине
  документа), plantuml, экспорт диаграмм, lazy-рендер по viewport,
  изменение темы/инициализации превью.

## Capabilities

### New Capabilities

- `mermaid-wysiwyg`: отображение mermaid-диаграмм в WYSIWYG-редакторе —
  рендер код-блоков в SVG, редактирование через модалку с живым превью,
  обработка ошибок, следование теме.

### Modified Capabilities

Нет: превью (SplitPreview) не меняется; preview-tabs/markdown-потоки
задействуются как есть.

## Impact

- `src/lib/` — новый модуль рендеринга диаграмм (обёртка над mermaid:
  ленивый импорт, id, offscreen-контейнер, ошибки) с тестами на хелперы.
- `src/lib/` — расширение редактора: nodeView на code-fence
  language=mermaid (приоритет Highest по уроку §10), без изменения
  сериализации.
- `src/components/Modals/` — модалка редактора диаграммы (Monaco + превью).
- `src/components/EditorArea/MarkdownEditor.tsx` — подключение расширения
  в combineExtensions.
- `src/components/EditorArea/EditorArea.css` — стили карточки/skeleton.
- i18n ru/en; новые зависимости не добавляются (mermaid 11.16, Monaco,
  Gravity Modal уже в проекте).
- Rust не затрагивается.
