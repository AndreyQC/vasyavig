# folder-colors

## Purpose

Визуальная идентификация корней workspace цветом: фиксированная палитра,
авто-выдача, фоновый тинт секций дерева и вкладок, широкая рамка активной
вкладки, нейтральный серый для файлов вне корней.

## ADDED Requirements

### Requirement: Фиксированная палитра из 9 цветов

Система SHALL предоставлять фиксированную палитру из 9 хроматических цветов,
достаточно различимых между собой. Нейтральный серый в палитру не входит и
зарезервирован для файлов вне корней workspace.

#### Scenario: Выбор цвета из палитры

- **WHEN** пользователь меняет цвет корня
- **THEN** доступные варианты — ровно 9 цветов палитры, серого среди них нет

### Requirement: Авто-выдача цвета новому корню

Новому корню цвет SHALL назначаться автоматически по кругу палитры, предпочитая
цвета, не занятые другими корнями. Пользователь может сменить цвет корня на
любой цвет палитры в любой момент; смена цвета применяется немедленно ко всем
местам, где цвет отображается.

#### Scenario: Три корня

- **WHEN** пользователь подряд добавляет три папки в пустой workspace
- **THEN** корни получают три разных цвета палитры

#### Scenario: Больше корней, чем цветов

- **WHEN** в workspace уже 9 корней и добавляется десятый
- **THEN** десятому назначается цвет уже используемый другим корнем

#### Scenario: Смена цвета корня

- **WHEN** пользователь меняет цвет корня с голубого на оранжевый
- **THEN** секция дерева и все вкладки этого корня сразу отображаются
  оранжевым тинтом

### Requirement: Цветовой тинт секции дерева

Секция дерева корня MUST иметь фоновую заливку лёгким тинтом цвета корня,
различимую в светлой и тёмной темах. Соседние секции с разными цветами
визуально разделяются.

#### Scenario: Тинт в обеих темах

- **WHEN** сайдбар отображает секции корней в светлой и затем тёмной теме
- **THEN** тинт каждой секции остаётся различимым и не делает текст нечитаемым

### Requirement: Цветовой тинт вкладок

Вкладка файла MUST нести лёгкий тинт цвета корня, к которому файл относится.
Вкладки файлов вне корней workspace несут нейтральный серый тинт.

#### Scenario: Вкладки разных корней

- **WHEN** открыты файлы двух корней разных цветов
- **THEN** вкладки различимы по тинту соответствующих цветов

#### Scenario: Файл вне корней

- **WHEN** открыт файл, не принадлежащий ни одному корню
- **THEN** его вкладка имеет нейтральный серый тинт

### Requirement: Широкая рамка активной вкладки

Активная вкладка MUST выделяться широкой рамкой насыщенного цвета своего корня
(нейтрального серого — для файлов вне корней). Неактивные вкладки рамки не
имеют. Заливка активной вкладки цветом, применяемая сегодня, убирается:
активность обозначается только рамкой и тинтом корня.

#### Scenario: Переключение вкладок

- **WHEN** пользователь активирует другую вкладку
- **THEN** широкая рамка появляется у новой активной вкладки и исчезает у прежней

#### Scenario: Активная вкладка вне корней

- **WHEN** активен файл вне корней workspace
- **THEN** его вкладка выделяется широкой серой рамкой

### Requirement: Отнесение файла к корню по самому глубокому совпадению

Цвет вкладки определяется корнем с наиболее длинным совпадающим префиксом пути
файла (наиболее специфичным корнем).

#### Scenario: Файл во вложенном корне

- **WHEN** корни `C:/docs` (голубой) и `C:/docs/guides` (розовый), открыт файл
  `C:/docs/guides/intro.md`
- **THEN** вкладка файла окрашена розовым тинтом
