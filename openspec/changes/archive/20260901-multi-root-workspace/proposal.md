# Proposal: multi-root workspace с цветами папок

> Дата: 2026-09-01 | Статус: draft
> Контекст: чекпойнт `_docs_/_checkpoints_/20260831_002_checkpoint.md`, обсуждение в сессии.

## Why

Приложение работает ровно с одной папкой: открытие новой уничтожает сессию —
дерево, watcher, а при несохранённых вкладках требует подтверждения. Документация
часто размазана по нескольким репозиториям и папкам, и «выбрать одну» означает
терять контекст остальные. Мульти-корневой workspace (как в VS Code) снимает
ограничение, а цветовая маркировка корней даёт мгновенную визуальную навигацию:
по дереву, по вкладкам и по активному документу всегда видно, к какому проекту
относится файл.

## What Changes

- Модель «одна открытая папка» заменяется на **workspace — упорядоченный список
  корневых папок** (**BREAKING** для внутренней модели `fileStore`; для
  пользователя ломающих изменений нет — одиночная папка вырожденный случай).
- Добавление/удаление корней; drag-and-drop папки в окно **добавляет** корень
  (сейчас — заменяет).
- Каждому корню присваивается **цвет из фиксированной палитры на 9 цветов**
  (авто-выдача по кругу, сменяемый); цвет применяется фоновым тинтом к секции
  дерева корня и ко вкладкам его файлов.
- **Активная вкладка** выделяется широкой рамкой насыщенного цвета своего корня
  (вместо сегодняшней заливки активной вкладки).
- Файлы вне корней workspace (Ctrl+O, drag файла) — нейтральный серый.
- Персистентность — **файл workspace** `.vasyavig-workspace` (JSON):
  автозапись при каждом изменении, относительные пути к файлу где возможно;
  последний открытый workspace восстанавливается на старте.
- Rust-watcher смотрит все корни одним `RecommendedWatcher` (несколько `watch()`);
  событие `fs-change` несёт путь, чтобы обновлять только затронутое дерево.
- Dirty-промпт переезжает с «открыть папку» на «убрать корень с несохранёнными
  вкладками» и «открыть другой/новый workspace».

## Capabilities

### New Capabilities

- `multi-root-workspace`: workspace как список корневых папок — добавление и
  удаление корней, вложенные корни, файлы вне корней, живое автообновление
  деревьев каждого корня.
- `workspace-file`: формат и поведение `.vasyavig-workspace` — структура JSON,
  автозапись при изменениях, относительные пути, восстановление последнего
  workspace на старте приложения.
- `folder-colors`: палитра из 9 цветов, авто-выдача и смена цвета корня,
  применение цвета фоновым тинтом в дереве и вкладках, широкая рамка активной
  вкладки, нейтральный серый для файлов вне корней.

### Modified Capabilities

Нет — основных спеков в `openspec/specs/` ещё нет, это первый change.

## Impact

- `src/store/fileStore.ts` — `rootPath: string | null` → `roots: RootInfo[]`,
  операции add/remove/refresh по корню; селекторы по уроку LESSONS_LEARNED §3.
- `src/components/Sidebar/` — секции-корни (заголовок + цвет + контекст-меню),
  переработка шапки Phase 6.
- `src/components/EditorArea/EditorTabs.tsx` + `EditorArea.css` — тинт вкладки
  по корню, широкая рамка активной; рамка не должна ломать flex/scroll-цепочки
  (урок §8).
- `src/hooks/useDragDrop.ts` — drop папки = добавление корня; `useFileWatcher.ts`
  — точечный refresh по пути из события.
- `src-tauri/src/commands/watcher.rs` — один watcher на несколько путей,
  payload у `fs-change`; проверять только с рестартом `tauri dev` (урок §11).
- `src/store/uiStore.ts` — путь последнего workspace в persist.
- Локали `src/locales/{ru,en}` — новые строки.
- Тесты: vitest (`fileStore`, резолвинг путь→корень), cargo-тесты watcher.
