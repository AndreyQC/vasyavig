## 4. Редактирование текстовых файлов

- [x] 4.1 `MonacoViewer.tsx`: проп `editable` (readOnly: !editable),
  `onChange` → `editorStore.updateContent`; для text-вкладок редактируемый
  режим, подсветка/wordWrap без изменений. Проверка: правка `.sql` живая,
  при переключении вкладок и возврате текст сохраняется (урок §5).
- [x] 4.2 `editorStore.ts`: `saveTab`/`saveAllDirty`/`saveActiveAs` допускают
  `kind: "text"` (условие `kind !== "markdown" && kind !== "text"`);
  `isMdYfmSwap` остаётся только для markdown. Проверка: unit-тесты — dirty
  text-вкладка сохраняется по Ctrl+S-потоку, error сохраняет dirty,
  «Сохранить все» включает text.
- [x] 4.3 «Сохранить как» для text: диалог с фильтром текущего расширения,
  вкладка переезжает на новый путь (`writeAndMove`), kind не пересчитывается.
  Проверка: unit-тест + ручной прогон Ctrl+Shift+S на `.json`.
- [x] 4.4 Сквозной ручной прогон: правка `.txt`/`.sql`/`.json` → dirty →
  Ctrl+S; закрытие dirty text-вкладки → промпт; возврат текста к исходному
  снимает dirty; preview-вкладка закрепляется первой правкой.
