# image-viewer Specification

## Purpose

Просмотр графических файлов (иллюстраций документации) прямо в приложении:
изображение открывается в отдельной вкладке редактора с вписыванием в область
и зумом, без внешних программ и без изменения самого файла.

## ADDED Requirements

### Requirement: Открытие изображения в отдельной вкладке

Выбор файла изображения в файловом дереве, диалог Ctrl+O и перетаскивание
файла в окно SHALL открывать изображение в отдельной вкладке с именем файла.
Вкладка изображения подчиняется семантике preview-вкладок: одиночный клик по
дереву — эфемерная preview-вкладка, двойной клик — закреплённая.

#### Scenario: Одиночный клик по изображению в дереве

- **WHEN** пользователь однократно кликает файл `logo.png` в дереве
- **THEN** открывается preview-вкладка с изображением и становится активной

#### Scenario: Изображение через Ctrl+O

- **WHEN** пользователь открывает изображение через диалог Ctrl+O или
  перетаскивает файл в окно
- **THEN** открывается закреплённая вкладка с изображением

#### Scenario: Повторное открытие того же изображения

- **WHEN** вкладка изображения уже открыта и пользователь снова открывает
  этот файл
- **THEN** вторая вкладка не создаётся, существующая активируется

### Requirement: Поддерживаемые форматы изображений

Система SHALL открывать во вкладке-просмотрщике файлы с расширениями
png, jpg, jpeg, gif, webp, bmp, svg, ico. Прочие расширения SHALL обрабатываться
как неподдерживаемые (существующее поведение: сообщение об ошибке, вкладка
не открывается).

#### Scenario: Известный формат

- **WHEN** пользователь открывает файл `diagram.webp`
- **THEN** файл открывается во вкладке-просмотрщике изображений

#### Scenario: Неизвестный формат

- **WHEN** пользователь открывает файл `scan.tiff`
- **THEN** показывается сообщение о неподдерживаемом типе, вкладка не открывается

### Requirement: Безопасное отображение

Изображение SHALL отображаться только из локального файла через asset protocol
в пределах уже выданных грантов каталогов; удалённые и сетевые URL SHALL NOT
запрашиваться. SVG SHALL рендериться в режиме, исключающем выполнение скриптов
и навигацию по ссылкам внутри файла.

#### Scenario: SVG со встроенным скриптом

- **WHEN** открывается SVG, содержащий `<script>` и обработчики событий
- **THEN** изображение отображается как картинка, скрипт не выполняется

#### Scenario: Файл вне выданных грантов

- **WHEN** файл изображения недоступен через asset protocol (нет гранта
  на каталог)
- **THEN** в области вкладки показывается заглушка с сообщением об ошибке
  загрузки, приложение продолжает работать

#### Scenario: Битый файл изображения

- **WHEN** открывается повреждённый файл с расширением png
- **THEN** в области вкладки показывается заглушка с сообщением об ошибке
  загрузки, приложение продолжает работать

### Requirement: Вписывание и масштабирование

По умолчанию изображение SHALL быть вписано в область вкладки с сохранением
пропорций (целое изображение видно без обрезки). Пользователь SHALL иметь
возможность изменять масштаб: кнопки «увеличить/уменьшить», Ctrl+колесо мыши,
переключатель «вписать / 100%». При масштабе, превышающем область, SHALL
появляться прокрутка. Диапазон масштаба SHALL быть ограничен (не менее 10%
и не более 1000%).

#### Scenario: Открытие с вписыванием

- **WHEN** открывается изображение больше области вкладки
- **THEN** оно масштабируется так, чтобы целиком поместиться в область,
  обрезки нет

#### Scenario: Увеличение масштаба

- **WHEN** пользователь нажимает «+» (или Ctrl+колесо вверх) на вписанном
  изображении
- **THEN** масштаб увеличивается шагом, появляются полосы прокрутки при
  выходе за границы области

#### Scenario: Переключение 100%

- **WHEN** пользователь переключает режим на «100%»
- **THEN** изображение показывается в натуральном размере пикселей;
  возврат режима «вписать» возвращает вписывание

### Requirement: Вкладка изображения не редактируется

Вкладка изображения SHALL быть только для просмотра: она никогда не получает
статус dirty, Ctrl+S не выполняет записи файла, закрытие вкладки происходит
без подтверждения.

#### Scenario: Ctrl+S на вкладке изображения

- **WHEN** активна вкладка изображения и пользователь нажимает Ctrl+S
- **THEN** файл не перезаписывается, статус вкладки не меняется

#### Scenario: Закрытие вкладки изображения

- **WHEN** пользователь закрывает вкладку изображения
- **THEN** вкладка закрывается сразу, без промпта о несохранённых изменениях
