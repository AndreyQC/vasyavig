  остальной текст не сжимается, узкие таблицы без полосы; каретка в ячейке за
  краем прокручивает блок к себе.
- [ ] 1.2 Превью: CSS для таблиц в панели split-превью (design D2). Проверка:
  ручная — та же широкая таблица в split: скролл у таблицы, панель превью не
  скроллится по горизонтали целиком.
- [ ] 1.3 Регресс переноса строк: обычные абзацы и узкий контент рендерятся как

## 3. Preview-вкладки

- [ ] 3.1 `editorStore`: флаг `preview` у `EditorTab`; `openTab` c опцией —
  preview-открытие закрывает предыдущую preview-вкладку другого пути,
  закреплённое открытие существующей preview её закрепляет; закрепление при
  переходе в dirty внутри `updateContent` (design D4). Проверка: vitest —
  сценарии спеки: последовательные preview A→B→C оставляют одну вкладку,
  повторный клик по тому же файлу не создаёт дубль, первая правка закрепляет,
  закреплённые вкладки не закрываются, preview не бывает dirty.
- [ ] 3.2 `fileStore.openFile(path, {preview})` (дефолт — закреплённая) и
  проводка из дерева: одиночный клик — preview, `onDoubleClick` в
  `FileTreeNode` — закреплённая. Проверка: vitest на проводке стора + ручная —
  одиночный/двойной клик по файлу с уже открытой preview закрепляет её.
- [ ] 3.3 Визуальное отличие preview-вкладки: курсив подписи (design D6).
  Проверка: ручная — preview и закреплённая вкладки различимы, в обеих темах.
- [ ] 3.4 Явные открытия — закреплённые: drag-and-drop файла, Ctrl+O, вкладка
  после конвертации office. Проверка: ручная — все три пути дают закреплённую
  вкладку при открытой preview.
