## Что сделано

### Детектор `ner` (`src/lib/agent/masking/ner.ts`)

| Источник | Что даёт |
|---|---|
| `ru-compromise` 0.0.4 (ESM, MIT) | `#Person/#FirstName/#LastName` термы с точными offsets → PERSON; `#City/#Country` → LOC; соседние person-термы через пробел сливаются в один спан («Иван Петрович Смирнов» — один алиас, N2) |
| `lvovich` 2.1.0 (CJS, MIT) | `getMiddlenameGender` — фильтр кандидатов-отчеств (N3) |
| Свои regex (5 правил) | инициалы «И. И. Иванов» / «Иванов А.С.» / «Петров А.» (N4); отдельно стоящее отчество (N3); юр. формы + имя в кавычках/1–3 слова — весь спан «ООО Ромашка» (N5); гео-подсказки `г./ул./просп./...` — значение = имя без ключа (N6) |

`\b`/`\w` нигде — только lookaround (критерий §8). Все кандидаты через общий
`mergeSpans` longest-wins (R8): «Иванову И. И.» целиком побеждает части.

### Интеграция

- `types.ts`: `DetectorId + "ner"`; `detectors.ts`: `detectText` добавляет
  `detectNer(text)` перед mergeSpans (D3 — сменный детектор, каркас не менялся).
- `config.ts`: `MaskingDetector + "ner"`; **дефолтные детекторы
  `[secrets, email, phone, ner]`** (N8) — preview-подтверждение делает
  автовключение безопасным; явный список в существующем конфиге не меняется.
- Превью T1b показывает PERSON/ORG/LOC чипы без правок UI; в словарь промпта
  типы попадают автоматически (D9). entitytype-i18n уже была (T1b).

### Кнопка «NER» в тулбаре (требование пользователя)

- `src/components/Toolbar/NerButton.tsx`: паттерн «Связей» — Popover-дропдаун,
  бейдж **общего количества** вхождений на кнопке; строки «тип · значение ·
  стр. N»; клик — переход к вхождению. Кнопка видна всегда на markdown-вкладках
  (в отличие от «Связей»), при нуле — empty-state в поповере.
- `src/hooks/useNerSpans.ts`: дебаунс-скан 400 мс после ввода (N10); скан
  локальный, от masking-конфига не зависит — это навигация, не отправка.
- Навигация (N11): смещение → 0-based строка raw-markdown →
  `editor.moveCursor({line})` (editorRegistry) — работает в WYSIWYG (data-line)
  и Markup (CodeMirror), скроллит и ставит курсор.
- Иконка `PersonMagnifier`; стили `.ner-panel*` в `EditorArea.css` (скролл
  только у списка, `overscroll-behavior: contain` — §8).

## Известные ограничения / NOT done

- Словарь ru-compromise ограничен: «Петербург» без юр. формы/гео-ключа не
  ловится; бренды без юр. формы — 0 % (доменный словарь `addWords` — открытый
  вопрос диалога §10).
- Склонённые фамилии без инициалов/отчества («Иванову» в дат.) не ловятся;
  полный охват — T3 (ручная разметка) и T3b (связность).
- «ИП Иванов И. И.» уходит в ORG (юр. форма побеждает в merge) — осознанно.
- lvovich принимает любое заглавное X-ич (форма, не словарь) — фильтр
  страховочный, реальный FP-класс на -ич в текстах мал (замер §6: <1 %).
- Кнопка NER — только markdown-вкладки (группа «Оглавление/Связи»); text —
  после GUI-приёмки при необходимости.
