## 1. Цель

1. Детектор `ner` в общем реестре детекторов маскирования (D3): типы
   **PERSON / ORG / LOC** на правилах — `ru-compromise` + `lvovich` + свои
   regex. После T1b сущности автоматически появляются в превью отправки.
2. Кнопка **«NER»** в тулбаре markdown-вкладок (рядом с «Оглавление» и
   «Связи», паттерн HarnessLinksButton): дропдаун-поповер со списком найденных
   вхождений, общее количество на кнопке, клик по вхождению — переход к нему
   в документе (требование пользователя, 2026-11-04).

Критерии приёмки диалога §8: отчество/инициалы/юр.формы/гео на русских
фикстурах; `\b` нигде не используется; ложные срабатывания по согласованной
метрике (§6: отчество <1 %, юр. формы ~2 %, гео-подсказки — фильтровать).

## 2. Решения

- **N1. Состав детектора** (`src/lib/agent/masking/ner.ts`, `detectNer(text)`):
  - `ru-compromise` 0.0.4: `match('#Person' | '#City' | '#Country')` c
    `json({offset: true})` — точные символьные позиции термов (замер спика:
    `text.slice(start, start+len)` совпадает; 0.24 мс/документ);
  - `lvovich` 2.1.0: `getMiddlenameGender` — фильтр кандидатов-отчеств
    (проверено: Ильич/Кузьмич/Сулеймановна → male/female; плечи/ключ/врач →
    null);
  - свои regex: инициалы+фамилия, юр. формы, гео-подсказки.
- **N2. Слияние PERSON.** Соседние `#Person`-термы через один пробел — один
  спан («Иван Петрович Смирнов» — полный текст одним алиасом). Все кандидаты
  (ner + правила + ru-compromise) проходят общий `mergeSpans` longest-wins
  (R8) — «Иванову И. И.» целиком побеждает отдельные части.
- **N3. Отчество.** Regex: заглавная + суффикс
  `-ович/-евич/-ич/-овна/-евна/-инична`, lookaround по кириллице; фильтр
  lvovich — отсекает обычные слова на «-ич». Отдельно стоящее отчество —
  тоже PERSON (~95 % полноты, <1 % FP — §6).
- **N4. Инициалы.** Два шаблона PERSON: `И. И. Иванов` и
  `Иванов И. И.` / `Иванов А.С.` (точка-без-пробела учтена).
- **N5. Юр. формы.** `(ООО|ПАО|ОАО|ЗАО|НАО|АО|ИП|ГК|ФГУП|МУП|НКО|ФНС|ИФНС|...)`
  + имя: `«...»` в кавычках или 1–3 капитализированных слова. Весь спан
  («ООО Ромашка») — значение ORG: идентичность по полному наименованию.
- **N6. Гео.** Сокращение (`г|гор|ул|просп|пр-т|ш|шоссе|бул|наб|пер`)+`.` +
  заглавное слово — тип LOC, значение = имя без ключевого слова (ключ виден,
  как KEY=value R5; «улица ≠ город» больше не конфликт — всё LOC). Плюс
  словарь ru-compromise `#City`/`#Country` (именительный падеж).
- **N7. `\b`/`\w` нигде** — только lookaround `(?<![А-Яа-яЁё])…(?![А-Яа-яЁё])`
  (критерий §8, ловушка JS по кириллице).
- **N8. Конфиг.** `MaskingDetector` + `"ner"`; дефолтные детекторы —
  `["secrets", "email", "phone", "ner"]`: preview-режим с подтверждением
  делает автовключение безопасным, а критика «персоны не ловятся» из
  чекпоинта закрывается по умолчанию. Явный список в существующем
  `vasyavig.yaml` не меняется (тот же принцип, что с mode).
- **N9. Интеграция.** `detectText` при `enabled.has("ner")` добавляет спаны
  `detectNer` до `mergeSpans`. Превью T1b показывает PERSON/ORG/LOC чипы без
  изменений UI (entityType-i18n уже есть). Модель получает типы в словаре
  плейсхолдеров (D9) автоматически.
- **N10. Кнопка «NER»** (`src/components/Toolbar/NerButton.tsx`): Popover как
  у «Связей», бейдж количества на кнопке; в поповере — строки «тип ·
  значение · строка N», клик — переход. Скан документа — дебаунс 400 мс
  (`src/hooks/useNerSpans.ts`), только markdown-вкладки; скан не зависит от
  masking-конфига (это навигация по документу, ничего никуда не отправляется).
- **N11. Навигация.** Смещение символа → 0-based строка raw-markdown →
  `editor.moveCursor({line})` из editorRegistry — работает в WYSIWYG
  (data-line) и Markup (CodeMirror), скроллит к строке и ставит курсор.

## 5. Риски и ограничения

- **CJS в тестах/бандле.** ru-compromise — CJS; vitest и Vite поднимают его
  штатно (проверяется прогоном). Если optimizeDeps закапризничает —
  `server.deps.inline`/alias не нужен, пакет самодостаточный (спик §6).
- **Словарь ru-compromise ограничен:** «Петербург» без юр. формы/гео-ключа не
  ловится (замер: только «Москва»); бренды без юр. формы — 0 % (доменный
  словарь — открытый вопрос диалога §10, механизм `addWords` заложен).
- **Склонения:** «Иванову» (дат.) ru-compromise не метит как Person;
  lvovich-фильтр — nominative-only. Спан ловится только в конструкциях с
  инициалами/отчеством. Осознанное ограничение T2; полнота вырастет в T3
  (ручная разметка) и T3b (связность сущностей).
- **Бандл:** +390 КБ raw / ~114 КБ gzip (ru-compromise) + 6.5 КБ (lvovich) —
  в рамках согласованных D2 (~120 КБ gzip).
- Кнопка NER — markdown-вкладки (группа «Оглавление/Связи»); text-вкладки —
  после GUI-приёмки, если понадобится.
