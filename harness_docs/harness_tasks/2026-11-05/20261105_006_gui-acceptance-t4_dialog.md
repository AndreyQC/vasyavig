## Дефекты

| № | Шаг | Описание | Приоритет | Статус |
|---|---|---|---|---|
| D-1 | C1/C4 | **Индекс сущностей в UI не перечитывается после сохранения.** `updateEntitiesIndexForContent` (save-хук) пишет `entities.jsonl` и обновляет кэш модуля, но `NerButton`/`EntityMarkButton` держат снимок списка в React-состоянии (`useEffect` только по `path`). Вотчер инвалидирует кэш (B-5), но компонент файл не перечитывает — до смены вкладки новые записи в UI не видны. Следствие: ручная разметка склонения в той же сессии не находит только что сохранённую запись и создаёт дубль ULID без предупреждения | P1 | открыт |
| D-2 | C4 | **Разметка до сохранения файла не знает о только что размеченных сущностях** (индекс пишется на save). Два размеченных значения в одном заходе не связываются, даже если одно — склонение другого | P2 | открыт |
