## Как ведём журнал

- Пользователь выполняет шаги чек-листа и пишет результат в чат ZCode.
- Агент переносит результат сюда (запись = шаг + факт + вердикт) и отмечает
  статус в чек-листе.
- Дефекты — в раздел «Дефекты» с номером D-1, D-2, …; решения по ходу — в
  раздел «Решения».
- Коммит журнала — по завершении приёмки (вместе с result-документом).
