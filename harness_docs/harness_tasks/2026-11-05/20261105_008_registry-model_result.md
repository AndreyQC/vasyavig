## Ключевые находки

1. **Алиас должен проверяться раньше наблюдаемой формы.** Иначе «John Smith» (ручной
   алиас) проиграет записи, где эта же строка встретилась как форма.
2. **Связи и со-occurrence — разные силы.** Явная связь (`works_at`) сильнее
   выведенной (`co_occurs`); в `resolveByRelations` это различено весом.
3. **Профиль co-occurrence** считается по документам (`пара ULID → счётчик +
   список документов`), хранит top-20 соседей на сущность — иначе растёт
   квадратично.
