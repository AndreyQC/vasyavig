## Ключевые находки (спайки lvovich 2.1.0)

1. **Косвенная база не склоняется**: `inclineLastname("Иванову", …)` возвращает
   слово как есть во всех падежах. Решение (T3d-4): база генерации — первая
   «склоняемая» форма из (canonical + forms), детекция — genitive меняет
   слово. Косвенный canonical без nominative-форм — только безопасные
   перестановки инициалов.
2. **«Анна» признаётся и именем, и отчеством** (`getMiddlenameGender` =
   female) — наивный findIndex ломал разбор. Решение: отчество — только
   **последнее слово** (порядок ФИО).
3. **Разговорные отчества** («Иваныч») вне словаря lvovich — суффикс-фолбэк
   `-(о/е)вич|ьич|ыч|ич|овна|евна|инична`; само слово при склонении
   остаётся как есть (безопасно).
4. **Порождение инициалов**: canonical «Иванов Иван Иваныч» даёт и
   инициальные формы «Иванову И. И.» / «И. И. Иванову» (оба стиля:
   «А. С.» и «А.С.»).

## Известные ограничения / NOT done

- Генерация надёжна только от nominative-базы; canonical в косвенном падеже
  без nominative-форм в истории — связывает только точным совпадением
  (выравнивается переутверждением эталона или первой разметкой в nominative).
- Сгенерированные формы **не пишутся** в `entities.jsonl` (слой матчинга);
  наблюдаемые дописываются как раньше — при разметке/сохранении.
- Суффикс-фолбэк отчеств может признать фамилию на -ич («Брич») отчеством
  при разборе трёхсловного ФИО — fp-риск мал (нужны и фамилия, и имя рядом).
- GUI-приёмка не выполнялась (вместе с T4).
