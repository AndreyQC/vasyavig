## Цель

1. Сущности справочника видны **в тексте** без разметки документа.
2. NER-предложения пополняют **справочник**, а не документ.

## T6-3. Runtime-подсветка

### Механика

- Новое ProseMirror-расширение `registryHighlightExtension` (рядом с
  `vasEntityExtension.ts`): декорации по вхождениям форм справочника.
- Формы → индекс: одна регулярка на все формы (экранирование), границы слова.
- Только формы ≥3 символов; формы короче — пропускаем (иначе «Иван» ловит всё).
- Склонения — через `expandEntityForms` (уже есть).
- **Неоднозначные формы** (одна форма → несколько ULID) подсвечиваются иначе:
  двойной бейдж / «неоднозначно» — сигнал для панели конфликтов (T6-5).

### Переключатель

- В тулбаре markdown-вкладки — кнопка-иконка «Показать сущности» (по умолчанию
  включено в режиме просмотра, выключено в разметке).
- Состояние — в `uiStore` (глобальное) или в `editorStore` (per-вкладка);
  решение: **глобальное** в `uiStore` + пер-вкладное отключение не нужно.

### Ограничения

- Только WYSIWYG (в Markup-режиме декорации не строятся — как и у чипов).
- Производительность: декорации пересчитываются при изменении текста; кэш
  скомпилированной регулярки на каталог.

## T6-4. NER → справочник

### Действия у NER-предложения

| Действие | Что делает |
|---|---|
| **«В справочник»** | новая сущность: тип + canonical + форма → запись в `entities.jsonl`, **документ не меняется** |
| **«Разметить»** (есть) | чип-якорь в документе (точечный якорь) |
| **«Привязать к existing»** | форма уже есть в справочнике → предложение связать (тот же ULID) |

### Для однофамильцев

- Если форма совпадает с существующей сущностью, но пользователь хочет
  **другого** человека — действие «Создать отдельную» + предложение связи
  (`works_at` и т.п. — T6-5).

### Где хранится

- Запись справочника — через `entitiesIndexStore` (T6-2) или прямой вызов
  `writeEntitiesIndex`; без панели (T6-2) — достаточно функции записи.

## Риски

1. Ложные срабатывания подсветки (короткие формы, подстроки) — порог длины,
   границы слова, только формы справочника, переключатель.
2. Подсветка в больших документах — кэш регулярки, ленивая загрузка форм.
3. «В справочник» без указания типа → тип спрашивается в поповере.
