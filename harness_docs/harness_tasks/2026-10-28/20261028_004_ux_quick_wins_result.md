## Известные ограничения

- Browser accelerator keys WebView2 отключены (фикс `af0e701`): Ctrl+P/Ctrl+W
  и пр. обрабатывает приложение. F12 в dev открывает DevTools через команду
  `open_devtools`; в release-сборке DevTools из клавиатуры недоступны (как и
  раньше — CDP-отладка не зависит от этого). Встроенный Ctrl+F (панель поиска
  WebView2) тоже не появится — поиска в редакторе пока нет (обзор, п. 10).
- «Закрыть другие/справа/все» при нескольких dirty-вкладках: закрывает чистые
  сразу и промптит только по первой dirty; остальные dirty закрываются
  повторным вызовом команды (промпты не наслаиваются, потери правок нет).
- Позиция курсора в WYSIWYG — «блок верхнего уровня:офсет» (приближение к
  строке:столбцу); в Markup — настоящие строка:столбец.
- Восстановление вкладок после рестарта (обзор, п. 11) и настройки редактора
  (п. 8) — не делались, остались кандидатами.

## Чек-лист ручной приёмки (dev-сборка `pnpm tauri dev`, перезапуск обязателен — Rust-команды create_dir/open_devtools + accelerator keys)

1. **Ctrl+P открывает палитру, а НЕ диалог печати** (проверено пользователем
   2026-10-28: печать открывалась — исправлено в `af0e701`, перепроверить).
2. Ctrl+W закрывает активную вкладку; dirty-вкладка промптит.
3. Ctrl+Tab / Ctrl+Shift+Tab переключают вкладки по кругу.
4. Палитра: ввод фильтрует файлы всех корней; Up/Down двигают выделение;
   Enter/клик открывают файл; Esc закрывает.
5. Средний клик по вкладке закрывает её.
6. Правый клик по вкладке — меню «Закрыть / Закрыть другие / Закрыть справа /
   Закрыть все»; dirty-вкладки промптят.
7. Контекст-меню дерева: «Новая папка» создаёт каталог (появляется в дереве),
   «Копировать путь» кладёт путь в буфер + тост.
8. Пустое состояние (без открытых файлов): кнопки «Открыть файл» и «Открыть
   папку» работают.
9. Статус-бар: «строка:столбец» обновляется в WYSIWYG и в Markup; при смене
   вкладки не остаётся чужая позиция; тултип бейджа расширения показывает
   полный путь.
10. «Сохранить всё» появляется активной при dirty-вкладках и сохраняет их;
    заголовок окна имеет «● » при несохранённых и теряет его после Ctrl+S.
11. Меню workspace: секция «Недавние» (до 5, свежий сверху); открытие недавнего
    с dirty-вкладками промптит; после перезапуска приложения список на месте.
12. F12 в dev-сборке открывает DevTools (штатный WebView2-F12 отключён вместе
    с accelerator keys).
