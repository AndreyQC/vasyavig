## Известные границы (помечать «н/д», не дефекты)

- подсветка только в WYSIWYG (Markup-режим и превью — без декораций);
- подсветка регистрозависима (согласовано с `matchEntityEntry`);
- «голая» фамилия без инициалов/полного ФИО не склоняется (граница T3d);
- связь при «Это он» не записывается автоматически (вручную в редакторе);
- профиль co_occurs — по активному документу (кэш `cooccurrence.json` — NOT done);
- перепись якорей слияния — только открытые вкладки;
- unused без постоянного списка «оставлено»; changed/missing — подписи «по якорям»;
- открытые дефекты T4: D-2 (P2), LOC-склонения (P3), «сущностей: N» vs счётчики (P3).
