## Ключевые решения Phase 8

- `propose_*` не меняют буфер: модель предлагает, приложение показывает diff
  и применяет после подтверждения; `apply_proposal` — app-only.
- Stale-правка — оптимистичная блокировка: `baseHash` + точный `oldText` +
  `expectedCount`; блокирующих lock нет.
- Пути: opaque `docId`/`rootId`; для создания — относительный путь внутри
  открытого корня, канонизация, запрет `..`, абсолютных путей и symlink;
  расширения `.md/.yfm/.txt`; overwrite по умолчанию запрещён.
- Ошибка модели: короткий retry, затем выбор другой модели; авто-fallback нет.
- Конфиг можно передавать: без env-ключа Fernet crypto-значения бесполезны.
