## Что это за проект

Vasyavig — лёгкий desktop-редактор Markdown/YFM на Tauri v2 + React + Zustand +
Gravity UI (WYSIWYG/Markup/Split), файловое дерево с watcher, спеллчек (zspell),
конвертация офисных документов через anydoc, i18n ru/en. С 2026-08 в нём же
живёт **AI-ассистент по документам** (Phase 8): панель справа, детерминированная
проверка документа, «Письмо HTML», и с 8.5 — псевдонимизация (маскирование
перед отправкой в модель + разметка сущностей `vas-entity:`).

## Решения и ограничения

- Тип в href (`vas-entity:person:01J…`); строка jsonl — 4 поля
  `{ulid, type, canonical, forms}`; токен типа lowercase.
- Автозапись сущностей отклонена — «предложения + кнопка» (D11).
- Один якорь harness-репо — `harness.yaml`.
- Точное совпадение приоритетнее сгенерированных форм (fuzzy — второй проход).
- Значения сущностей только в памяти стора (D8): в audit и на диск не пишутся.
- `src-tauri/target` почищен: удалены `target/release` (3,6 ГБ) и
  `target/debug/incremental` (5,7 ГБ); `debug/deps` (12 ГБ) оставлен ради
  скорости пересборок. `cargo clean` — в конце серии работ.
