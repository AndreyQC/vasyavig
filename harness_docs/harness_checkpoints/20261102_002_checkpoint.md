## Что это за проект

Vasyavig — desktop-редактор markdown/YFM на Tauri 2 + React 19 + Zustand +
Vite. Основной сценарий — harness-документация: реестр документов, граф
связей, ULID-ссылки, конверты, задачи, TOC. Phase 8 добавляет ассистента
по документам; модель — в периметре, по OpenAI-совместимому протоколу.

## Реализовано в 8.1

- `vasyavig.yaml` рядом с `.vasyavig-workspace`; пустой/отсутствующий файл ->
  defaults в памяти, первый save создаёт файл.
- Валидация схемы: несколько моделей, `default_model`, `request`
  (timeout/retries/backoff), `capabilities`, `data_scope`, app-секции.
- `api_key` принимается только как `crypto__<ENV>__<ciphertext>`; plain-ключ
  — ошибка валидации. `base_url` тоже может быть crypto-токеном.
- Неизвестные секции и ключи сохраняются при записи (YAML Document);
  невалидный файл не перезаписывается, `writable=false`.
- Переключение модели атомарно перезаписывает `default_model`; при ошибке
  записи выбор остаётся в памяти, UI показывает ошибку.
- Rust: Fernet encrypt/decrypt, генерация ключа, резолв токенов; тест с
  реальным Python-токеном.
- Rust: `stream_chat` через `reqwest` (native-tls/schannel), сырые байты в
  `Channel`, таймауты, connect timeout, лимит 8 MiB, обрезка тела HTTP-ошибки.
- Отмена: реестр run-id, флаг проверяется каждые 200 мс, в том числе на
  «зависшем» стриме.
- Provider: толерантный SSE-парсер (границы чанков, UTF-8), non-stream JSON,
  `data: [DONE]`, `error`-payload, retry только 5xx/429/сеть и только до
  первого текста, capabilities `streaming`/`json_mode`.
- UI: панель справа, селектор модели, add/edit/remove, проверка endpoint,
  шифрование ключа, генерация Fernet-ключа, путь и статус конфига,
  кнопки «Перечитать» и «Открыть конфиг».
- `vasyavig.yaml` открывается read-only: Monaco без редактирования,
  save/save-as отключены (по имени файла).
- i18n ru/en для всех новых строк.

## Ключевые решения и ограничения

- **TLS:** в `reqwest` 0.13 `default-tls` — это rustls + aws-lc (C-сборка).
  Используется явный `native-tls`; на Windows это schannel, `openssl` в
  build-граф не попадает. `Cargo.toml` фиксирует это комментарием.
- Секреты не логируются и не попадают в plaintext-конфиг; crypto-команды
  возвращают ошибки без значений.
- Сеть — только `POST {base_url}/chat/completions`; shell/FS/произвольных
  URL в ассистенте нет.
- Retry — короткий (из `llm.request.retries`), автоматического fallback
  на другую модель нет (D17/D21).
- Отмена — флаг run-id + `cancel_run`; при отмене частичный текст
  возвращается вызывающему, но не применяется к документам.
- `capabilities` — декларация пользователя: `json_mode` уходит в
  `response_format` только при `true`; `tools` пока не используются.
- Проверенный endpoint: `minimax-m2`, `context_limit` 110000,
  `max_tokens` 70000, `timeout_ms` 180000, capabilities
  `streaming=true`, `json_mode=true`, `tools=false`,
  `data_scope=perimeter`.
